
1. Request Salsa-Release 2 from https://www.coli.uni-saarland.de/projects/salsa/corpus/ and save the `salsa_release.xml` in the current folder.
2. Download the splits: from https://public.ukp.informatik.tu-darmstadt.de/naacl18-multimodal-frame-identification/salsa_splits.txt and save the file as `salsa_splits.txt` in the current folder.
3. Run `python convert_salsa.py`
4. Make sure a file `salsa.csv` exists
