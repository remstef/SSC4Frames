
1. Download FrameNet v1.7 from https://drive.google.com/open?id=1s4SDt_yDhT8qFs1MZJbeFf-XeiNPNnx7 (provided by https://github.com/swabhs/open-sesame) and save the tar.gz file in the current folder
2. Extract the tar file `tar -xzvf fndata-1.7.tar.gz`
3. Make sure a subfolder `fndata-1.7` exists
4. Run `python convert_fn17.py`
5. Make sure a subfolder `open_sesame_v1_data/fn1.7` exists and contains `*.conll` files
